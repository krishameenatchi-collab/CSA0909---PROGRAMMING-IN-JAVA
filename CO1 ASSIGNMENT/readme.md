## Description

This assignment implements and analyses an object-oriented Campus Smart-Parking System using Java.

The system demonstrates:

- Classes and objects
- Constructors
- Static members
- Inheritance
- Method overriding
- Polymorphism
- Abstract classes
- Interfaces
- Packages
- Access modifiers
- Encapsulation
- Arrays and jagged arrays
- Testing and complexity analysis
